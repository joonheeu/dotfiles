# zsh 환경

이 파일은 `~/.zsh-environment.md`로 심볼릭 링크되어 있으며, 관리 원본은
`~/.dotfiles/zsh/`입니다.

## 현재 기본 구성

- 셸: zsh
- 프롬프트: Starship만 사용하며, Oh My Zsh 테마는 비활성화합니다. 개발 정보형으로
  현재 경로, Git 브랜치·상태, 런타임 버전, 패키지 버전, 1초 이상 걸린 명령 시간을 표시합니다.
- Oh My Zsh: `git` 플러그인만 사용합니다.
- Zinit: `zsh-autosuggestions`, `fast-syntax-highlighting`만 사용합니다.
- 히스토리: 세션 간 공유하고 중복을 제거하며, 10,000개를 보관합니다.
- 로그인 환경: `.zprofile`에서 Homebrew와 mise를 초기화합니다.
- 디렉터리 이동: zoxide를 초기화했으며, `z <이름>`으로 자주 방문한 경로로 이동합니다.
- 대화형 대체 alias: `ls`/`ll`/`la`/`lt`는 eza, `cat`은 bat, `df`는 duf,
  `du`는 dust, `ps`는 procs, `top`은 btop, `grep`은 rg를 사용합니다.
- Git diff: Delta를 기본 pager와 interactive diff filter로 사용합니다.

## 설정 경계

- `~/.zshrc`는 인터랙티브 셸 설정입니다.
- `~/.zprofile`은 최소한의 로그인 셸 환경 설정입니다.
- `~/.config/starship.toml`은 프롬프트 모양을 관리합니다.
- Starship 초기화는 유일한 프롬프트 렌더러가 되도록 `.zshrc`의 마지막에 둡니다.
- 플러그인은 반복적으로 필요한 작업을 해결할 때만 추가합니다.

## 추가 후보

- `Aloxaf/fzf-tab`: Tab completion 목록을 fzf로 검색·선택합니다. `fzf`는 이미 설치되어 있습니다.
- `zsh-users/zsh-completions`: 특정 CLI의 기본 completion이 부족할 때만 추가합니다.
- `wfxr/forgit`: 터미널 기반 Git 검토와 stage 작업이 반복될 때만 추가합니다.

Oh My Zsh와 Zinit 양쪽에 자동 제안, 문법 강조, 프롬프트, Git 기능을 중복 추가하지 않습니다.
