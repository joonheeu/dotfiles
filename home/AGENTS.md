# 홈 환경 자동화 안내

홈 환경의 관리 원본은 `~/.dotfiles`이며, `~/scripts`는 그 저장소의
`scripts/`를 가리키는 심볼릭 링크입니다. 홈 폴더에서 자동화·설정·점검을
추가하거나 변경하기 전에 아래 문서를 순서대로 읽습니다.

1. `~/.dotfiles/AUTOMATIONS.md` — 자동화 목록, 위험도, 예약 상태, 후속 조치
2. `~/scripts/AGENTS.md` — 스크립트 위치, 작성·검증·보안 규칙
3. 관련 카테고리와 스크립트 — 호출 방식과 기존 동작

## 작업 원칙

- 새 자동화의 원본은 홈 폴더가 아니라 `~/.dotfiles/scripts/<category>/`에 둡니다.
- 먼저 읽기 전용 상태 점검 또는 `--dry-run`을 제공하고, 실제 변경은 `--apply` 등
  명시적인 동작으로 분리합니다.
- 삭제, 덮어쓰기, 권한·인증·시크릿 접근, 네트워크 변경, 예약 실행은 각각 별도
  위험으로 보고 사용자 승인 없이는 수행하지 않습니다.
- 자동 실행은 재생 가능한 저위험 파일에만 적용합니다. 범위가 넓은 `rm -rf`, Docker
  prune, Downloads·캐시·로그 정리 등은 사용자가 개별적으로 검토하기 전까지 예약하지
  않습니다.
- 새 자동화에는 목적, 대상, 사전 조건, dry-run/확인 방법, 로그 위치, 복구 방법,
  스케줄 여부를 `AUTOMATIONS.md`에 기록합니다.
- 스크립트 변경 후에는 문법 검사와 가장 작은 안전한 실행 검증을 합니다. 기존의
  사용자 변경, 시크릿 파일, `.ssh`는 범위 밖으로 유지합니다.

## 빠른 점검

현재 상태와 필요한 후속 조치는 아래 명령으로 확인합니다.

```zsh
~/scripts/system/home-automation-status
```

zsh·Starship의 별도 운영 메모는 `~/.zsh-environment.md`를 참고합니다.
